# 读平台链接设计说明（抖音、小红书、快手、微博、B站）

2026-10-23 用户：「微信那个需要爬虫视频号抖音小红书这些平台的公开内容，让他们都能看到才对，我发链接转发都能收到看到」「AI 扒取公开视频，这个不能靠云端，只能把源码扒下来才行」「你先做各个平台爬虫公开内容」。

## 1 为什么用本机浏览器（10-23 实测）

- 普通请求（curl，桌面浏览器 UA）：小红书发现页跳登录页；抖音首页只回 2.4KB 的验证脚本；微博跳访客验证；快手 63 字节；只有 B站正常。
- Edge 无界面模式（--headless=new --dump-dom）：抖音给「验证码中间页」；小红书 0 字节；快手 228 字节；微博能看。
- 真窗口的 Edge（不登录、窗口放屏幕外）：抖音首页、作品页能读（作品页要等 8 秒以上内容才画出来）；小红书笔记（带 xsec_token 的链接）能读出作者、点赞、话题、正文、图片、视频地址；快手精选页能读、有视频地址；微博能看。
- B站作品页 412「安全风控」：页面上写的访问 IP 是 107.172.147.220（洛杉矶机房）。这台电脑 10-13 起 v2rayN 是 TUN + 全局代理，所有流量都从国外出去（curl myip.ipip.net 也是这个 IP）；浏览器加 --no-proxy-server 也没用（TUN 在系统层）。要读 B站得用户在 v2rayN 里让国内站直连，网络设置不归我改（全局规矩）。
- MediaCrawler（开源，同样的思路：浏览器登录、在登录好的页面里取数据）许可证是「非商业学习许可 1.1」，不许商用，所以不搬它的代码，照原理自己写。

## 2 怎么做

- engine/PageBrowser.kt（共用）：PageBrowser 接口（snapshot 打开网址取数据、cookieNames、showForLogin、hide、running、close），SocialLinks（认平台、取数据的脚本、认「被拦了」、整理给 AI 的文字）。
- desktopMain/engine/EdgeBrowser.kt：用 Windows 自带的 Edge（没有就找 Chrome），单独的资料夹 <数据>/browser，--remote-debugging-port=0（端口从资料夹里的 DevToolsActivePort 读），--no-proxy-server，窗口放在 (-10000,-10000)，关掉被遮挡时降速的几个开关；用 OkHttp 的 WebSocket 说 Chrome 调试协议。每个链接开一个后台标签页，加载完后每 0.8 秒看一次正文长度，连两次不变（而且超过 200 字）就取数据，最多 15 秒，然后关标签页。AI集训营 退出时让它 Browser.close。上次没关掉的会接着用。
- 取数据（页面里执行的脚本）：标题、og 简介、正文文字（3 万字以内）、300×300 以上的图片、视频地址（去掉 blob: 和抖音的占位视频 uuu_265.mp4）；小红书再读 window.__INITIAL_STATE__ 里的笔记（标题、正文、作者、点赞、话题、图片、视频 masterUrl）。只读页面上已经显示给人看的东西，不调平台接口、不翻页、不批量。
- 被拦了（登录页、验证码、风控）：告诉 AI 如实说没读到，并说去 设置 → 联网搜索 → 读平台链接 点「去登录」。读到小红书笔记数据的不算被拦。
- 引擎：fetch_url 遇到这五家的链接走浏览器（同时最多两个页面），别的网址照旧；用户这句话里有网址时，没开「联网」也给 fetch_url。手机上没有浏览器（返回 null），手机遥控电脑时由电脑读。
- 设置 → 联网搜索 →「读平台链接」：每家登没登录（抖音 sessionid、快手 userId、微博 SUB、B站 SESSDATA；小红书游客也有 web_session，看不出来）、「去登录」（浏览器挪到屏幕上、打开那家首页，用户扫码）、「登好了，收起浏览器」。查状态时浏览器没开就不去开（不然一打开设置页就冒出一个 Edge），点「检查登录状态」才开。
- 自动测试不开真浏览器（Gradle 给测试设 -Djxy.browser=off）；PlatformLinksTest 用假浏览器；LiveBrowserTest（JXY_LIVE_BROWSER=网址,…，JXY_BROWSER_PROFILE=资料夹）真开 Edge 打印读到的东西。

## 3 没做 / 未确认

- 视频里说的话（转文字）：只给了视频地址，没下载、没转写。下一步：下载视频 → 抽音轨 → 用 设置 → 语音 的听写转文字。
- 视频号：只在微信里能看，网页打不开；转发视频号到 ClawBot 收到什么没试（iLink 只有文字 / 图片 / 语音 / 文件 / 视频五种条目）。
- 分享短链接（v.douyin.com、xhslink.com、b23.tv）靠浏览器自己跳转，没拿真短链接试（未确认）。
- 小红书不带 xsec_token 的链接（只有 /explore/编号）多半要登录，没试。
- 登录后能多读到什么（评论全量、私密内容不读）没试；平台的风控会不会因为频繁读封号：只读用户发来的链接，频率很低。
- B站：要用户的网络让国内站直连才能读。
- 平台的用户协议没逐条读原文（未确认）。
