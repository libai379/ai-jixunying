## 已知限制

- 手机端只是遥控器，电脑关机时手机用不了。
- 安卓端 HTTP 客户端走系统默认代理设置；如果手机 Wi-Fi 里设了 HTTP 代理，连电脑可能被代理劫走（还没遇到，记一笔）。
- 苹果端不做（需要 Mac）。
