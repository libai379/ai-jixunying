# 当前任务

更新于 2026-10-07 晚

## 状态

1.1.0 已打包（F:\apk-out\AI集训营.exe 和 AI集训营.apk），本地已提交。

这一版按用户第二轮反馈改的：
- 安卓用专用签名，和前身 App 的签名、包名都不同，不会覆盖安装（apksigner 核对过）。
- 手机端能单独用：内置完整引擎，模型直接从手机调用，数据存手机。模拟器上验证过。
- 联机改成全球可用：走公共 MQTT 中转 + 端到端加密，不用同一个 Wi-Fi，不用自己的服务器。去掉了只能局域网的旧方案。
- 九模型测评的模型按用户 WorkBuddy 里的准确写法放进预设，并显示测评名次和花费。
- 生图补齐国内各家：Seedream、千问图像 / 万相、可灵、CogView（含免费 cogview-3-flash）、MiniMax image-01、混元生图、文心 iRAG、阶跃、硅基流动、魔搭。
- 联网搜索加「自动」模式：Kimi / 智谱 / 千问用官方内置搜索，其他模型用我们的搜索工具。

已验证：
- 自动测试 8 项全过（含进程内 MQTT 的联机全流程、内置搜索、五种生图协议）。
- 真实公共中转实测：配对约 2 秒，一次指令往返约 0.5 秒，400KB 上传再下载约 1 秒。
- 模拟器端到端：用配对码配对电脑，从手机发消息电脑执行再推回手机；把电脑配置导入手机；手机本机单独调用智谱接口。
- 挂了约 80 分钟后手机仍连着电脑。

## 已知限制

- 手机遥控电脑时，电脑要开着并运行 AI集训营；电脑关着时手机切回「本机」照样能用。
- 公共中转是免费服务，没有服务保证；已经同时连三个入口（EMQX 两个 + HiveMQ），也可以在设置里换成自己的 MQTT 服务器。
- 手机本机的对话不会同步到电脑（电脑上的对话手机切到「电脑」就能看）。
