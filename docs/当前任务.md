## 已知限制

- 手机遥控电脑时，电脑要开着并运行 AI集训营；电脑关着时手机切回「本机」照样能用。
- 公共中转是免费服务，没有服务保证；已经同时连三个入口（EMQX 两个 + HiveMQ），也可以在设置里换成自己的 MQTT 服务器。
- 手机本机的对话不会同步到电脑（电脑上的对话手机切到「电脑」就能看）。
- 同步只从电脑到手机一个方向，只加不删：手机上删掉的成员，再按同步会从电脑那边加回来。
