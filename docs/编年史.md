## 2026-10-07

- 用户改方向：做成豆包 / WorkBuddy 那样的东西。要求：生成图片；输入图片和各种文档；回答要幽默风趣但正经，不要胡说八道（前身太娱乐、调侃收不住）；联网搜索；互相 @；AI 要认清自己、其他 AI 和人；桌面、安卓、苹果互通，不要服务器，桌面端就是移动端的服务器；用 API 但聊天内容存本地；填 API 时要有国内外各平台预设（参考用户给的「添加模型」截图）；界面重做，布局合理、美观大气。
- 用户拍板：在 ai-jixunying 里做（不改前身）；名字沿用 AI集训营；苹果先不做（不知道原生 iOS 需要 Mac）。
- 技术路线落地：Kotlin 2.4.0 + Compose Multiplatform 1.12.1 + AGP 9.2.1 + Ktor 3.5.0。模块 :shared（共用界面和协议，桌面引擎在 desktopMain）、:desktopApp、:androidApp。包名 com.guixing.jixunying。
- 架构：界面只认 Backend 接口；桌面是本地引擎，手机是 RemoteBackend 经局域网 WebSocket 连桌面。事件用同步监听器推送，保证「先事件后回执」的顺序。
- 防附和沿用构想：群聊默认「独立作答」，同一轮互相看不到；AI 之间 @ 接力限制轮数（默认 3）。
- 写完第一版，7 项自动测试通过，桌面 exe 和安卓 APK 都能打出来；桌面打包版独立运行验证过界面。没有真 Key，没跑真模型；安卓没上真机。
