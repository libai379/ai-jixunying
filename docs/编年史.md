## 2026-10-07（晚，第二轮）

- 用户反馈第一版很多地方不对：
  - 安卓签名要和老 App 不一样，不能覆盖安装老 App。
  - 只能局域网联机没有意义（人在电脑旁边就直接用电脑了），要隔半个地球也能联机，WorkBuddy 就是这样。
  - 手机端要能单独用，也能联机用。
  - 联网搜索是不是要单独一个 AI？别家怎么做的、哪个好？
  - 国内能画图的不止那几家。
  - 测评过的模型放进去了没有？
- 查清 WorkBuddy 的做法：手机 App 有「连接电脑」（远程指挥电脑，经腾讯云中转、同一账号）和「云端沙箱」（不连电脑单独用）两种；还能用微信 / 企业微信 / QQ / 钉钉 / 飞书远程指挥电脑（Claw）；三端对话记录实时同步。微信是官方 ClawBot，走微信云端中转 iLink，扫码接入。
- 读了用户 WorkBuddy 的模型清单（只读模型名和地址，Key 打码），拿到九个测评模型的准确写法：deepseek-flash（即 DeepSeek-V4.1-Flash）、deepseek-v4-pro、MiniMax-M3、glm-5.3、GLM-5.3-Flash、kimi-k3、qwen3.8-max（千问AI平台 maas.qianwenaiapi.com，即测评里的 Qwen3-Max）、mimo-v2.6-pro、mimo-v2.6-flash。WorkBuddy 的其他设置文件涉及凭据，系统不允许读，没碰。
- 改动：
  - 签名：生成专用密钥（G:\DevCache\signing），APK 证书「AI Jixunying」；前身是安卓调试证书，包名也不同。
  - 引擎从电脑独占改到两端共用（jvmShared），手机本机能单独用。
  - 联机：删掉局域网服务，改成两端都连公共 MQTT 中转（EMQX 两个入口 + HiveMQ），AES-256-GCM 端到端加密，二维码一次性配对；手机侧栏可在「本机 / 电脑」切换；可把电脑配置一键导入手机。
  - 联网：「自动」模式下 Kimi（$web_search）、智谱（web_search 工具）、千问（enable_search）用官方内置搜索，其余用我们的搜索工具。
  - 画图：新增百炼 / 千问AI平台（异步任务）、MiniMax、可灵、魔搭协议；预设补齐国内各家画图模型。
  - 预设加入九个测评模型，选模型时显示「测评第几 · 几分 · 花费」。
- 实测中发现公共中转的域名在变（broker-cn.emqx.io 已不在上海，解析到 AWS），长时间挂着的连接会变成「僵尸」：显示已连接却收不到消息。加了每 45 秒自测探针，150 秒收不到就拆掉重连；手机端很久收不到电脑回音也会重连（间隔逐渐拉长到 10 分钟）。
- 验证：8 项自动测试；真实公共中转实测；模拟器端到端（配对、遥控电脑聊天、导入配置、手机本机单独调用接口，挂 80 分钟仍在线）。打包 1.1.0。
