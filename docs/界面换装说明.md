# 界面换装：液态玻璃 + 弹簧动画（2026-10-22）

用户 10-22：「之前癸星科技里面有个液态 UI 设计，还有弹簧动画效果等等，也做进来，不然这个 UI 设计太垃圾了」「然后做ui，最后ui做完，提交，发行版，上传，安装都做」「一直做下去不要问我」。

## 1 来源

- 癸星科技（F:\guixingkeji，GKD 分支）：库 io.github.kashif-mehmood-km:backdrop:0.0.1-alpha02（Kyant0/AndroidLiquidGlass 的多平台分支，包名 com.kashif_e.backdrop）。Maven Central 上有 backdrop-android、backdrop-desktop（jvm）两个我们要的包；它照 Compose 1.9.3 编，我们是 1.12.1（更新），编过、截图过才算能用。
- 用户调好的参数 TunedGlassParams（F:\guixingkeji\app\src\main\kotlin\com\guixing\glasstuning\GlassTuningModel.kt:101）：圆角 36.2、模糊 0、折射高 48 / 量 64、depthEffect、vibrancy、色散开；高光关；阴影 6.27dp、偏移 (-0.41, 4)、颜色 0x4D000000、透明度 0.645。
- 弹簧和手感：DampedDragAnimation、InteractiveHighlight、DragGestureInspector、LiquidToggle、LiquidButton（都是从 Kyant0/AndroidLiquidGlass 的示例移植的，Apache 2.0，文件头保留出处）。

## 2 GKD 踩过的坑，这次直接照着避开（F:\guixingkeji\docs\PITFALLS.md、GLASS.md）

1. 采样源（layerBackdrop）只能是玻璃控件的同级兄弟，不能是祖先：祖先会让渲染树循环引用，安卓上是原生崩溃（SIGSEGV，Kotlin 异常日志里看不到，要 grep "fatal signal|tombstone"）。
2. 背景要画在挂 layerBackdrop 的那个节点自己的 drawBehind 里，拆成子组件画，采样回来是空的。
3. 色散（chromaticAberration）：库的色散着色器采样坐标没夹住，窄长面板、背后是真文字时会花屏；GKD 最后把背后有真内容的地方全关了。我们的玻璃一律不开色散（所以也不用搬 PatchedLens）。
4. 参数要在绘制阶段读（rememberUpdatedState），不然静止后玻璃冻在最后一帧。
5. 折射高度 / 量超过元素本身会读出界：夹到元素短边的 0.45 倍。
6. Color.copy(alpha) 是覆盖不是缩放。

## 3 怎么搭

1. 壁纸（GlassWallpaper）：整个窗口最底下一层，一个 drawBehind 画渐变 + 几团柔光（浅色、深色两套），自己挂 layerBackdrop；界面（MainLayout）是它的兄弟，盖在上面。CompositionLocal LocalGlass 把这个采样源和开关交给下面。
2. 玻璃面（Modifier.glass）：取 LocalGlass 的采样源，按用户调好的参数画（vibrancy → blur → lens，阴影照调好的），再铺一层半透明底色保证字看得清（大面积的面板铺得厚，按钮铺得薄）。关了玻璃或者没有采样源时，画成原来的纯色底 + 边框，样子和以前一样。
3. 用在哪：
   - 电脑的侧栏、手机的抽屉：大面积玻璃（模糊加重，字要清楚）。
   - 对话页、Code 栏的顶栏和输入框：玻璃。
   - 弹窗（AppDialog）：弹窗是另一个窗口，不能采样主窗口的壁纸（跨窗口画同一个图层，安卓上有崩溃风险），所以弹窗里自己垫一块小壁纸当兄弟采样源；出现时弹簧缩放 + 淡入。
   - 开关（AppSwitch，原来 4 处 Switch）：换成液态开关（能拖、按下变大、带速度挤压）。
   - 发送键、主要按钮：按下跟手的弹簧形变和高光（InteractiveHighlight，安卓那份用的 AGSL 着色器换成多平台都能画的径向渐变）。
   - 弹簧：侧栏选中项、弹窗出现、消息出现用 spring。
4. 设置 → 外观 加开关「液态玻璃」（默认开）。关掉就是原来的样子。存在 Settings.ui.glass；老版手机不认识这个字段，Settings.SCHEMA 加一并在 SaveSettings 里保留（CLAUDE.md 的规矩）。
5. 安卓 13（API 33）以下：库自己退化（31～32 只有模糊，31 以下没效果），我们铺的底色照样在，字看得清。

## 5 第二版：照癸星科技的模板抄（2026-10-24）

用户 10-24：「之前让你做的效果好像不太明显，还是用的之前那个模板，物理弹簧力学，和液态效果，你重新去看看之前癸星科技那个项目，照着模板抄也能抄下来」。

对照癸星科技（F:\guixingkeji）查出来差在三处：
1. 壁纸：癸星科技启动页 LauncherBackground（app\src\main\kotlin\com\guixing\LauncherActivity.kt）是四团浓光斑（紫 0xFF8B7CFF、青 0xFF3CE8D8、品红 0xFFFF5FC9、琥珀 0xFFFFB74D，深色底上 0.75～0.85），9 秒、7 秒一来回慢慢漂；我们的是淡淡的、不动的，玻璃折射不出东西。→ 照抄，漂移 ±30dp，在绘制阶段读，只重画壁纸这一层；浅色模式同一套颜色乘 0.55。截图测试里停着（jxy.wallpaper.still）。
2. 玻璃面：癸星科技 TunedGlassParams 是不模糊、折射 48 / 64、tint 关（表面一点底色都不铺）；我们顶栏、侧栏自己定了模糊 10～22、底色铺 55%～62%，折射全被盖住。→ 三种 GlassStyle 都改成 TunedGlassParams 的折射，不模糊，底色只铺 6%～38%（上面有字，留一点）。
3. 用得太少：只有十来处是玻璃，设置卡片是半透明纯色（当时怕滚动时卡）。→ 设置卡片（SectionCard）、手机设置首页每一项都换成真玻璃。
4. 弹簧：按下照启动页卡片（Spring.DampingRatioMediumBouncy、StiffnessMedium，松手会弹）；列表一条条出现照 rememberEntranceModifier（晚 90 毫秒一条、淡入 420 毫秒、从下面 24dp 用 LowBouncy 弹上来），侧栏对话、Code 会话、设置列表都加了。

可能的代价（未实测）：壁纸一直在动，开着玻璃时整个窗口每帧都要重画玻璃，电脑 CPU / GPU、手机耗电会比以前高；关掉「液态玻璃」就停。

## 6 液态玻璃调节（2026-10-24）

用户：「业态这一块儿，你只把它做进去了，那全套没有做进去。我怎么调整呢？而且你这个效果很垃圾，需要我自己去调整才行。」→ 照癸星科技的调参台（app\src\main\kotlin\com\guixing\glasstuning\GlassTuningActivity.kt、GlassTuningModel.kt）整套搬过来：设置 → 外观 → 液态玻璃调节。

- 位置（model/GlassTuning.kt 的 GlassTarget）：侧栏、顶栏和输入框、设置卡片、按钮和开关、弹窗，各存各的（Settings.glassTuning，SCHEMA 8，旧版发来的设置保留这一项）。没改过的用 GlassDefaults.of（就是改之前的样子，界面一像素不变）。
- 参数和癸星科技一样分组：形状（圆角，按钮不用）、模糊 / 折射（vibrancy、模糊半径、折射高度 / 强度、depthEffect、色散）、高光（细边 / 斜光 / 环境光，宽度、模糊、透明度、角度、衰减、强度）、外阴影、内阴影、染色。我们多一组「底色」（浅色 / 深色各一个厚度，颜色跟着主题），保证字看得清。
- 预览：和界面同一个 Modifier.glass（传 params），背景能换（界面壁纸 / 彩色渐变 / 纯色 / 文字），玻璃上放两行字，一直轻轻呼吸。拖滑块只改预览，松手才存（不然每拖一下写一遍设置，手机遥控电脑时还要过网）。
- 恢复默认（这一个位置）、复制参数（JSON）；预设：自带「AI集训营默认」「癸星科技调好的」（TunedGlassParams，色散关、底色 0），能把现在的存成新预设、应用、改名、删除。
- 和癸星科技不一样的地方：这一版库（kashif-mehmood-km backdrop 0.0.1-alpha02）HighlightStyle.Default / Plain 没有颜色参数，高光颜色不给调；电脑端 Ambient / Default 高光着色器和新版 skiko 不兼容，电脑上一律画成细边（页面上写明了）；色散没有搬 PatchedLens（只修安卓 AGSL），默认关、开了自己看，页面上写了会花屏。
- 液态按钮（发送键）用「按钮和开关」那一套参数，按下的形变和跟手高光是按钮自己的；液态开关的圆钮动画没接调参（照原样）。

## 7 第三轮（2026-10-24 晚）：透出下面的字、外观并一栏、自己的背景、取色器、侧栏、货币换算

用户：「这个输入框只留一个矩形就行，它是透明的，能透出下面的文字……液态玻璃和外观，这不是一个东西吗？为什么要分两栏？界面壁纸我添加不了自己的图片，色彩渐变纯色我自己改不了颜色……左边这个对话扣的什么我的文档、立场、AI 成员，这个框太宽了，要不你做细一点，要不可以变宽，变窄，可以收起那种。花费美元汇率……再加上一个功能，就是可以换算」。

- 输入框透出下面的字：对话页、Code 栏开着液态玻璃时，聊天记录 / 步骤列表一直排到底（底部留出输入框高度），输入框浮在上面；列表挂一层 layerBackdrop，输入框的玻璃用 rememberCombinedBackdrop(壁纸, 列表) 采样，滚动的字从玻璃下透出来、被折射。列表层和输入框是兄弟（采样源不能是玻璃的上级）。Code 栏开着终端时照旧（终端夹在中间）。
- 外观并一栏：设置里不再单独有「液态玻璃」，外观页一页里是 主题 → 背景 → 液态玻璃（开关 + 全套调节）→ 通用（代理、接力轮数）。
- 背景（Settings.background，SCHEMA 9）：默认 / 纯色 / 渐变 / 图片，照癸星科技 GlassBackground：采样层自己 drawBehind 画全；模糊另画一层给人看（不叠在采样层上）；纯色、渐变把亮度 / 对比度 / 饱和度算进颜色，图片挂色彩矩阵；透明度只给图片。图片从本机选，上传进数据（Backend.upload），按 id 取。弹窗自己照同一个画法画一份当采样源（GlassEnv.paint）。
- 取色器（ColorPicker.kt）：16 个预设、色相 / 饱和度 / 亮度三条、色号输入；背景、阴影、内阴影、染色都用它。
- 侧栏：三张小卡片改成一行图标 + 名字、下面一行状态，高度从 70 多压到 40 多；电脑上侧栏右边缘能拖（200～420dp，记在本机 sidebar.width），右上角能收起成一条窄边（sidebar.collapsed）。
- 货币换算：汇率那次联网顺带取 HKD、SGD、GBP、EUR、JPY（ExchangeRate-API 全量 rates；Frankfurter 加 symbols），存 costs.fx（1 美元换多少）；花费页「货币换算」卡片：人民币、美元、港币、新加坡元、英镑、欧元、日元任意两种之间按美元中转换算。10-24 实测两家都有这几种（ER-API 1 美元 = 6.684864 人民币、7.842579 港币、1.278163 新加坡元、0.747655 英镑）。
