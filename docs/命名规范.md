# 命名规范

所有地方统一叫「AI集训营」。旧名一律废弃。

## 统一写法

- 中文显示名（窗口标题、应用名、安装包名、文档标题）：AI集训营
- 英文 / 拼音标识（目录名、仓库名、Gradle rootProject、文件名）：ai-jixunying
- Kotlin 包名：com.guixing.jixunying
  - 理由：将来要并入癸星，癸星源码包名全是 com.guixing，放在它下面并入时不用改 package 行。
  - 状态：建议值，写第一行代码前请用户确认一次。
- Windows 安装包文件名：AI集训营.exe / AI集训营.msi（沿用癸星的习惯：文件名不带版本号和日期，版本看"关于"页）
- 模块名（Gradle）：:core（引擎，纯 Kotlin，桌面和安卓共用）、:desktop（Windows 界面）

## 功能名

- 会审模式：独立作答 → 匿名互评 → 主席汇总（用于日常提问和狼人杀投票）
- 集训场：狼人杀（带标准答案的对抗训练和测评）
- 自由群聊：保留的闲聊模式，明确标注"仅闲聊，结论不可靠"
- 记录员：负责压缩记忆的那个模型
- 主席：会审模式里负责汇总的那个模型（狼人杀里由警长担任）

## 旧名清单（前身 G:\ai-discussion-app 里出现过的名字，全部废弃）

- AI他妈（前身 CLAUDE.md 标题）
- aichatroom（capacitor appName、安卓 app_name、网页 title、manifest.json）
- ai-discussion-app（npm 包名、目录名）
- com.taiclear.taic（安卓 appId）——这个在前身里永远不能改，只是新项目不再使用

前身 App 不改名：改 appId 等于装一个新 App，手机里旧数据会丢；改显示名意义不大，因为前身不再发展。
