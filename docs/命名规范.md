# 命名规范

所有地方统一叫「AI集训营」。旧名一律废弃。

## 统一写法

- 中文显示名（窗口标题、应用名、安装包名、文档标题）：AI集训营
- 英文 / 拼音标识（目录名、仓库名、Gradle rootProject、文件名）：ai-jixunying
- Kotlin 包名：com.guixing.jixunying
  - 理由：将来要并入癸星，癸星源码包名全是 com.guixing，放在它下面并入时不用改 package 行。
  - 状态：2026-10-07 已定并启用（安卓 applicationId 同名），以后不许改。
- Windows 安装包文件名：AI集训营.exe / AI集训营.msi（沿用癸星的习惯：文件名不带版本号和日期，版本看"关于"页）
- 模块名（Gradle）：:shared（界面 + 协议 + 两端共用的引擎 jvmShared）、:desktopApp（Windows 入口）、:androidApp（安卓入口）
- Windows 安装包 jpackage 里的内部名用 ai-jixunying（避免非 ASCII），交付时改名为 AI集训营.exe；安卓交付名 AI集训营.apk
- 安卓签名：专用密钥 G:\DevCache\signing\ai-jixunying.jks（别名 jixunying，证书 CN=AI Jixunying），密码在仓库根目录 keystore.properties（不进 git）。和前身的调试签名不同。丢了就无法覆盖升级，不许删、不许换

## 功能名

- 会审模式：独立作答 → 匿名互评 → 主席汇总（用于日常提问和狼人杀投票）
- 集训场：狼人杀（带标准答案的对抗训练和测评）
- 自由群聊：保留的闲聊模式，明确标注"仅闲聊，结论不可靠"
- 记录员：负责压缩记忆的那个模型
- 主席：会审模式里负责汇总的那个模型（狼人杀里由警长担任）
