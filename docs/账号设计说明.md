# 账号设计说明（本机密钥 + GitHub）

2026-10-23 用户：「我说的是 AI 群这个软件登录，做一个这个软件登录，不设服务器的话有哪些途径」→ 我列了几条（本机密钥、GitHub 设备码、微信开放平台、短信、托管身份服务）→ 用户：「账号登录就用 GitHub 加密钥两种方式登录」。拉群暂停，账号先做出来，以后进群、证明「是我」用。

## 1 本机密钥账号（engine/Account.kt）

- 第一次用时生成 EC P-256（secp256r1）密钥对：Java 和 Android（API 26 起）都自带，不加依赖。
- 账号编号 = 「jxy-」+ 公钥（X.509 编码）SHA-256 的前 10 字节，十六进制每 4 位一段（例：jxy-1a2b-3c4d-5e6f-7a8b-9c0d）。
- 私钥只在 <数据>/account/identity.json（只给本人读写），**不进 state.json、不同步、不经联机线路**；state 里只有 AccountInfo（编号、建立时间、GitHub 用户名 / 名字 / 头像、正在登录时的码）。
- 签名：SHA256withECDSA（Account.sign / Account.verify），现在只测试用，以后进群时证明身份。
- 备份码：「JXYID1:」+ base64(盐 16 字节 + IV 12 字节 + 密文)，口令经 PBKDF2-HMAC-SHA256 20 万次得 AES-256 密钥，AES-GCM 加密整个 identity（私钥、公钥、GitHub 绑定）。口令至少 6 个字。导入时先验密钥是一对再换；导入会替换这台设备原来的账号（界面上红字提醒）。手机和电脑想用同一个账号就互相导。

## 2 GitHub 登录（网页跳转，跳回本机；docs.github.com/en/apps/oauth-apps/building-oauth-apps/authorizing-oauth-apps）

10-24 先做的是设备码登录：GitHub 那页要输 8 位码、一堆防钓鱼警告（请求来自哪个 IP、应用建了不到一天），授权按钮还常灰着，用户找不到也点不了。用户：「移动端和桌面端都一样，都是跳转登录，不要再搞出验证来」→ 换成网页跳转，电脑和手机同一套代码（jvmShared/engine/Account.kt）。

- 打开 https://github.com/login/oauth/authorize?client_id、redirect_uri=http://127.0.0.1:随机端口/auth/github、state、code_challenge（S256）；不传 scope = 只读公开资料。官方「Loopback redirect urls」原文："The redirect_uri does not need to match the port specified in the callback URL for the app."；PKCE："Must be S256"。
- 应用里登记的回调：http://127.0.0.1/auth/github（不开通配）。
- 跳回本机：和 ChatGPT 登录共用 ChatGptAuth.waitCallback（只认这一个路径，回一页「GitHub 登录好了」）；state 对不上不绑。浏览器会先开空的预连接，读 3 秒没东西就丢掉接着等（真登录第一次就因为这个报了 Read timed out）。
- 换令牌：POST https://github.com/login/oauth/access_token（client_id、client_secret、code、redirect_uri、code_verifier）。官方表格 client_secret 写 Required。拿到令牌只用一次：GET https://api.github.com/user 取 login、id、name、avatar_url，绑到本机账号上，**令牌不存**。
- 走设置里的代理。
- **client_secret 不进仓库**：放在本机 G:\DevCache\secrets\github-oauth-secret.txt，打包时 shared/build.gradle.kts 的 genSecrets 生成 engine/BuildSecrets.kt（在 build 目录里）。文件不在就生成空的，点登录提示「还没开通」。装出去的程序里带着它，等于公开（gh 命令行也是这样）；拿到它最多冒充「AI集训营」这个名字发起授权，用户还要自己点同意、只能跳回 127.0.0.1。换机器打包要先把这个文件拷过去（或者在 GitHub 应用页上再生成一个）。
- 第一次要在 GitHub 页面上点「Authorize」；同意过以后再登，GitHub 直接跳回，不停页面。

## 3 手机

- 手机自己的账号在手机上（本机引擎各有各的）；手机遥控电脑时，电脑的账号只看不改：PhoneGate 拒 AccountGitHubSignIn / Unbind / Export / Import（顺带也拒了 ChatGptSignIn、PlatformLogin——登录跳回的是电脑）。

## 4 测试

AccountTest：编号格式和再打开不变、签名验得过 / 改一个字验不过、备份码里没有明文私钥、口令错 / 乱码 / 口令太短报错、导入后编号一样；引擎里：私钥不进 state.json、假 GitHub 的跳转登录（授权地址参数、浏览器预连接和要图标的请求不影响、PKCE 和 client_secret 核对、state 对不上不绑）、绑定后编号不变、令牌不存、手机把关、导出导入解绑。
