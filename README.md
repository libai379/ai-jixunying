# AI集训营

让多家 AI 模型在规则约束下协作、对抗、互相审查的 Windows 桌面应用。
将来作为一个功能模块并入原生安卓应用「癸星」（F:\guixing）。

一句话定位：不是娱乐群聊，是一个**能量化"AI 会不会被带偏"的集训场**。
狼人杀有标准答案（谁是狼是确定的），所以是主要训练场和测评场；
在狼人杀里验证有效的防附和机制，再搬进日常的「会审模式」使用。

## 欢迎参考学习

这个仓库公开，里面的构想、踩坑记录（docs/教训库.md）和研究资料整理（docs/参考资料.md）大家都可以自由参考、学习、借鉴，拿去指导自己的多智能体项目也行。
如果对你有帮助，转载或引用时注明出处就好。有想法欢迎提 Issue 交流。
