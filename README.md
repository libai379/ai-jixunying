# AI集训营

把国内外的大模型拉进一个应用：单聊像豆包，群聊里多个 AI 能互相 @、互相纠错。
Windows 桌面端 + 安卓端，两边都能单独用；手机配对电脑后，在任何地方（不用同一个 Wi-Fi）都能遥控电脑上的 AI集训营。
不需要自己的服务器：两边都连免费的公共中转，内容端到端加密，中转只看得到乱码。聊天记录、附件、API Key 都只存在你自己的设备上。

## 下载

到 [Releases](https://github.com/libai379/ai-jixunying/releases) 下载最新版：

- 电脑：AI-Jixunying-版本-日期-windows.exe，Windows 10 / 11（64 位），双击安装；新版直接覆盖安装，聊天记录和设置都在。
- 手机：AI-Jixunying-版本-日期-android.apk，Android 8.0 以上；新版直接覆盖安装。Release 说明里有每个文件的 SHA-256 和安卓签名指纹，可以核对。

## 功能

- 单聊和群聊；群聊默认「独立作答」，每个 AI 各答各的、互相看不到，避免跟风附和；答完可以互相 @ 补充或纠错
- 点名：不用 @，直接喊名字（「阿麦，画一张图」「让阿德来算一下」）就只有被叫到的回答；只是提到名字（「阿麦说得不对，大家怎么看」）大家照常回答
- 立场档案：群聊里有答案的问题，记下每位成员一开始怎么说、后来谁改了口、为什么改（被说服、跟风、迎合你、自己查证）；你标一下谁对，每位成员一张卡：首答准确率、坚持度、跟风、被带偏、被纠正——就是当初立项想量化的「AI 会不会被带偏」
- 中立裁判和 AI 核实：立场由单独的裁判模型来记（默认 DeepSeek-V4.1-Flash，可以换），给裁判看的聊天可以隐去成员名字（成员甲 / 乙 / 丙）；开新议题后裁判会自己联网查一次谁对，你没标的题可以按它的结论算，你标的永远优先
- 每位成员可以选「默认 / 快速 / 深度」：快速少想快答，深度想透再答（各家模型的切换参数不一样，查不到的平台不让选）
- 花费：每次调用模型、每张图都记账，按官方价格算钱（单价能自己改），按成员、模型、用途、天看；能直接查 DeepSeek、Kimi、硅基流动等平台的余额
- 后台出错提示：压缩聊天、记长期记忆、点名、立场档案、AI 核实在后台出错时会告诉你哪里坏了、去哪改
- 每个 AI 知道自己是谁、背后是什么模型，也知道群里还有谁、用户是谁
- 说话规矩：正经回答为主，幽默点到为止；不知道就说不知道；时效性问题先联网搜索再答，并标出处
- 联网搜索：智谱、千问用平台官方内置搜索，Kimi 用 Kimi 官方搜索接口；其他模型用免费的必应，也可以换博查、智谱、Tavily、Brave
- 发图片给能看图的模型；发 PDF、Word、Excel、PPT、代码、文本，自动转成文字给模型读
- 做 Word、Excel、PPT：说「做成 Word」「整理成表格发我」「做个汇报 PPT」，成员直接交给你一个 .docx / .xlsx / .pptx 文件，点开就用 Office / WPS 打开；Word 有通用、正式、公文三套排版，Excel 的数字、百分比、金额、日期能直接计算，自动冻结表头、加筛选、算合计；PPT 有五套配色，封面、目录、章节页、表格页自动排，字多了自动拆页，讲稿放进演讲者备注；每条回答也能「存成 Word」；微信里要的文件直接发回微信
- 画图：豆包 Seedream、千问图像 / 通义万相、可灵、智谱 CogView、MiniMax、混元生图、文心 iRAG、硅基流动、魔搭、OpenAI 等；不用专门设置，配好的服务商里能画的自动用上（画质优先：千问图像排第一，画里的中文字写得准；某家余额用完自动换下一家；免费的智谱 cogview-3-flash 垫底）
- 记忆：聊得太长时记录员把前面压成摘要（群里共用一份）；关于你的长期记忆所有对话、所有成员都能用，能看能改；AI 能翻以前的聊天
- 本地文档：电脑和手机各自给设备里的文档建索引，在聊天里问「我那份合同里写的付款日期是哪天」，AI 会自己搜、自己读
- 微信助理：扫码绑定（腾讯官方 ClawBot 接口，和 WorkBuddy 的微信助理一样），在微信里发文字、图片、文件给它，AI 回答；电脑和手机都能接——电脑开着就电脑答，电脑关了由手机接着答（手机自动用电脑的同一个绑定，不重复回答，各有开关）；手机上在微信里「用其他应用打开」文件也能直接交给 AI
- 服务商预设：DeepSeek、智谱、Kimi、MiniMax、千问、通义百炼、豆包、小米 MiMo、腾讯混元 / TokenHub、百度千帆、阶跃、美团 LongCat、硅基流动、魔搭、OpenAI、Claude、Gemini、Grok、Mistral、Groq、OpenRouter、Ollama 等，都按 OpenAI 兼容协议接入
- 手机扫电脑上的二维码配对；手机可以一键同步电脑上配好的模型、成员和记忆

## 技术

Kotlin 多平台 + Compose Multiplatform，桌面和安卓共用界面和引擎代码。联机走 MQTT 公共中转（EMQX、HiveMQ），AES-256-GCM 端到端加密。
